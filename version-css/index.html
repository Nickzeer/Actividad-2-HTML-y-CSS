NUESTRA RAZÓN DE SER

Pequeños cuidados.
Grandes cambios.

Un refugio, muchas segundas oportunidades

Huella Segura es un refugio ficticio de Manabí creado para este proyecto académico. Su sistema organiza los reportes de animales rescatados y facilita el seguimiento de cada caso.

La empatía es el primer paso. Un registro claro ayuda a que el equipo sepa dónde, cuándo y cómo intervenir.
