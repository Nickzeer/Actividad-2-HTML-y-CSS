# Validación del proyecto

Fecha: 23 de octubre de 2026.

Los seis HTML se comprobaron con el [validador W3C](https://validator.w3.org/nu/). Todos respondieron con 0 errores y 0 advertencias. Las respuestas del servicio están en evidencias/validacion-w3c.json.

- index.html
- reportar.html
- rescates.html
- version-css/index.html
- version-css/reportar.html
- version-css/rescates.html

También se revisaron los enlaces, las imágenes y las secciones del menú. Ningún HTML incluye scripts y el proyecto no contiene archivos JavaScript.

En el navegador se comprobó que el formulario exige nombre, categoría, urgencia y descripción antes de enviarse. Después del envío abre rescates.html. La tabla mantiene sus tres ejemplos porque este prototipo solo usa HTML y CSS y no guarda datos.
